# AI Tooling History

This document records the prompts used with AI tools during the development of the **ApexMotors Car Dealership Inventory System**.

---

# AI Tools Used

- ChatGPT
- Bolt AI
- DeepSeek

---

# 1. Project Planning (ChatGPT)

## Context

The project requirements document was first provided to ChatGPT.

## Prompt

```
Analyze the provided project requirements document.

Generate the overall structure and architecture of the website.

Create a complete development plan for the project.

Also build a checklist of every task mentioned in the document and divide the tasks based on priority (High, Medium, Low) so that I can implement the project step by step.
```

## Purpose

- Understand the project requirements
- Design the overall application architecture
- Plan the development workflow
- Break the project into manageable milestones

---

# 2. UI Design (Bolt AI)

## Context

The website structure generated by ChatGPT was then provided to Bolt AI.

## Prompt

```
Generate a professional metallic finish UI for the website.

Use a modern dark theme with clean layouts.

Add all the features mentioned in the project document.

Keep the UI responsive, professional, and easy to navigate.

Focus on a premium car dealership design with glassmorphism and metallic accents.
```

## Purpose

- Generate UI layouts
- Design reusable React components
- Create a premium user interface
- Improve responsiveness

# Development Workflow

1. Analyzed the project requirements using ChatGPT.
2. Generated the project architecture and implementation roadmap.
3. Created a prioritized development checklist.
4. Used Bolt AI to design the frontend based on the planned structure.
5. Implemented the frontend and backend incrementally.
6. Used ChatGPT and DeepSeek throughout development for debugging, backend implementation, optimization, and testing.
7. Generated project documentation after completing the application.

---

# Human Verification

All AI-generated content was reviewed, modified, and tested before being integrated into the final project.

AI tools were used as development assistants, while all final implementation decisions, integration, debugging, and verification were performed manually.
